4. Designing URI Paths & Resources
Plural Naming Convention: Always use plural nouns for collection resources (e.g., /users, /organizations) rather than singular nouns [
01:18
Opens in a new window].

Hierarchical Nesting:

Root Collection: /users

Individual Item: /users/{id}

Sub-resource / Related Items: /users/{id}/orders

Clean & Readable URIs: Avoid using file extensions (e.g., .json, .php) or implementation details in the URI path.



HTTP Status Codes Guidelines
2xx Success:

200 OK: General successful fetch or update.

201 Created: Resource successfully created (typically returned with POST).

204 No Content: Successful request with no body returned (e.g., after a DELETE).

4xx Client Errors:

400 Bad Request: Invalid body or missing required parameters.

401 Unauthorized: Authentication missing or invalid.

403 Forbidden: Authenticated, but user lacks permission.

404 Not Found: Target resource does not exist.

422 Unprocessable Entity: Valid syntax, but validation failed on business logic.

5xx Server Errors:

500 Internal Server Error: Server encountered an unhandled exception or crash.
